

# My Data Analytics Portfolio  

Welcome to my repository! 🚀 Here, you'll find a collection of projects showcasing my skills in data analysis, visualization, and automation using various tools and technologies.  

## 📌 Technologies Used  
- **SQL** – Data querying, transformation, and database management  
- **Python** – Data manipulation, automation, and analytics using libraries like Pandas, NumPy, and Matplotlib  
- **Tableau** – Interactive dashboards and storytelling with data  
- **Excel** – Advanced formulas, pivot tables, and VBA for automation  
- **Power BI** – Business intelligence, data modeling, and DAX calculations
